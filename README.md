## About

Zylos is a versatile and powerful desktop application built with Flutter, designed to offer an extensive set of tools via modular plugins. With an advanced, unified installer, Zylos provides users the flexibility of both full offline installations (pre-packaged with essential plugins) and online installations (downloading the latest plugins on the fly).

### Key Capabilities

- **Video Downloading**: Powered by yt-dlp with support for thousands of websites
- **Media Conversion**: Built-in FFmpeg integration for format conversions
- **VPN Integration**: Cloudflare WARP for secure, private connections
- **Plugin System**: Modular architecture for extensibility
- **Cross-Platform**: Works seamlessly on Windows and Android

---

## 🌟 Features

### Core Features

- **🔄 Hybrid Installer**: Choose between Online mode (downloads latest plugins) and Offline mode (uses bundled plugins for environments with no internet access)
- **📹 Video Downloading**: Integrated with `yt-dlp` (supports Stable, Nightly, and Master builds) for comprehensive media downloading from 1000+ sites
- **🎬 Media Conversion**: Seamlessly utilizes `FFmpeg` for fast and reliable media processing and conversions
- **🔒 Secure Connections**: Built-in integration with `Cloudflare WARP` to ensure secure, private network traffic right out of the box
- **⚡ Auto Startup**: Configure Zylos to run automatically when your system starts
- **🔌 Plugin System**: Modular plugin architecture for easy extensibility
- **📋 Playlist Support**: Download entire playlists with a single click
- **🎯 Quality Selection**: Choose from multiple quality options before downloading
- **📊 Download Queue**: Manage multiple downloads simultaneously
- **🌐 Bulk Operations**: Convert multiple files in batch mode

### Platform-Specific Features

#### Windows
- Native Windows integration with system tray support
- Drag-and-drop URL input
- Windows notification support
- Single instance enforcement

#### Android
- Material Design UI
- Background download support
- Storage access framework integration

## 📦 Installation

### Prerequisites

- **Windows**: Windows 10 or later (64-bit)
- **Android**: Android 8.0 (API level 26) or later
- Internet connection (for Online installation mode)

### Installation Steps

#### Method 1: Universal Installer (Recommended)

1. Download the latest **Zylos v3.0** release:
   
   | Installer Type | Description | Download |
   | :--- | :--- | :--- |
   | **Universal Setup** | Complete installer with all components | [⬇️ Download](https://github.com/YasirSDQ/Zylos/releases/download/Zylos_v3.0/Zylos_Universal_Setup.exe) |
   | **Online Setup** | Lightweight installer (downloads components during install) | [⬇️ Download](https://github.com/YasirSDQ/Zylos/releases/download/Zylos_v3.0/Zylos_Online_Setup.exe) |
   | **Offline Setup** | Standalone installer (no internet required) | [⬇️ Download](https://github.com/YasirSDQ/Zylos/releases/download/Zylos_v3.0/Zylos_Offline_Setup.exe) |

2. Run the downloaded installer

3. Choose your installation mode:
   - **🌐 Online Installation**: Fetches the latest versions of yt-dlp, FFmpeg, and WARP (requires internet)
   - **💾 Offline Installation**: Installs the pre-bundled versions (perfect for offline environments)

4. Select the plugins you want to include:
   - ☑️ yt-dlp (Video Downloader)
   - ☑️ FFmpeg (Media Converter)
   - ☑️ Cloudflare WARP (VPN)

5. Choose installation directory (default: `C:\Program Files\Zylos`)

6. Click "Install" and wait for completion

7. Launch Zylos from the Start Menu or Desktop shortcut

## 📖 Usage Guide

### Quick Start

1. **Launch Zylos** from your Start Menu or desktop shortcut

2. **Copy a video URL** from any supported website (YouTube, Vimeo, Twitter, etc.)

3. **Paste the URL** in the input field on the home screen

4. **Click "Fetch"** to retrieve video information

5. **Select your preferred quality** and format

6. **Click "Download"** to start the download

7. **Access your downloaded files** from the Library tab

<div align="center">

![Quick Start Guide](https://raw.githubusercontent.com/YasirSDQ/Zylos/5023f01d092535641c9ab54f9329ead0fe08152b/Images/Screenshots/Download%20Features.png)

*Download your first video in 6 easy steps*

</div>

### Advanced Features

#### Playlist Downloads

1. Paste a playlist URL
2. Zylos will detect it's a playlist
3. Choose to download all videos or select specific ones
4. Set quality preferences
5. Start batch download

#### Media Conversion

1. Navigate to the "Converter" tab
2. Add video/audio files (drag & drop or browse)
3. Select output format (MP4, MP3, AVI, MKV, etc.)
4. Configure conversion settings
5. Click "Convert"

#### Using the VPN Feature

1. Go to Tools → VPN/WARP
2. Toggle the switch to enable
3. Wait for connection establishment
4. Your traffic is now secured through Cloudflare WARP

#### Plugin Management

1. Open Settings → Plugin Manager
2. View installed plugins
3. Install new plugins from the repository
4. Update existing plugins
5. Enable/disable as needed

## 🔌 Browser Extension

Zylos includes a browser extension for Chrome, Edge, and Firefox that enhances the downloading experience.

### Features

- **One-Click Download**: Add videos to Zylos directly from the browser
- **Context Menu Integration**: Right-click on videos to download
- **Batch URL Import**: Send multiple URLs at once
- **Download Status**: View active downloads from the browser

### Installation

#### Download Extension (v3.0)

Download the latest extension package: **[zylos_extension_3.0.zip](https://github.com/YasirSDQ/Zylos/releases/download/Zylos_v3.0/zylos_extension_3.0.zip)**

#### Manual Installation

1. Download and extract the `zylos_extension_3.0.zip` file
2. Open your browser's extension management page
   - Chrome/Edge: `chrome://extensions/`
   - Firefox: `about:addons`

3. Enable "Developer Mode"

4. Click "Load unpacked"

5. Navigate to the extracted `zylos_extension` folder

6. The extension will be installed

#### PowerShell Script (Windows)

```powershell
# Run as Administrator
cd "C:\Program Files\Zylos\zylos_extension"
.\install_extension.ps1
```

### Usage

1. Navigate to a webpage with a video

2. Click the Zylos extension icon

3. Select the video(s) you want to download

4. Click "Send to Zylos"

5. Zylos will open and begin fetching video information

## ❓ FAQ

### General Questions

**Q: Is Zylos free to use?**  
A: Yes, Zylos is completely free and open-source.

**Q: Is it legal to download videos?**  
A: Downloading videos may violate terms of service of some websites and copyright laws in your jurisdiction. Only download content you have rights to or that is explicitly licensed for downloading.

**Q: Which platforms are supported?**  
A: Currently, Zylos officially supports Windows and Android. Linux and macOS builds are experimental.

### Technical Questions

**Q: What's the difference between Online and Offline installation?**  
A: Online installation downloads the latest versions of yt-dlp, FFmpeg, and WARP during setup. Offline installation uses pre-bundled versions, making it ideal for air-gapped systems.

**Q: Why isn't a video downloading?**  
A: Possible reasons:
- The website is not supported
- The video is DRM-protected
- The website has blocked our IP
- yt-dlp needs to be updated

Try updating yt-dlp in the Plugin Manager or check if the site is listed in supported sites.

**Q: How do I update Zylos?**  
A: Currently, manual update is required. Download the latest installer from GitHub Releases and run it over your existing installation.

**Q: Where are downloaded files stored?**  
A: By default:
- Windows: `C:\Users\[Username]\Downloads\Zylos\`
- Android: `/storage/emulated/0/Download/Zylos/`

You can change this in Settings.

**Q: Can I resume interrupted downloads?**  
A: Yes, Zylos supports resuming interrupted downloads automatically.

### Troubleshooting

<div align="center">

| Issue | Solution |
| :--- | :--- |
| **"Plugin not found" error** | Reinstall the plugin from Plugin Manager |
| **Slow download speeds** | Try enabling WARP VPN or check your internet connection |
| **Conversion fails** | Ensure FFmpeg is properly installed and updated |
| **App crashes on startup** | Delete the Hive database files in `%APPDATA%\Zylos` |
| **Videos won't play after download** | Try a different format/container or update your media player |

</div>

For more help, please [open an issue](https://github.com/YasirSDQ/Zylos/issues) on GitHub.
