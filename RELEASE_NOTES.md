# Zylos v3.0 Release 🚀

Welcome to **Zylos v3.0**! This release brings a versatile and powerful desktop application built with Flutter, designed to offer an extensive set of tools via modular plugins.

## 📥 Download Assets

| File | Size | Type | Description |
| :--- | :--- | :--- | :--- |
| **`Zylos_Universal_Setup.exe`** ⭐ | ~158 MB | Installer | Hybrid installer (Online/Offline mode). Recommended for most users. |
| **`Zylos_Online_Setup.exe`** | ~13 MB | Installer | Lightweight installer. Downloads latest plugins during setup. |
| **`Zylos_Offline_Setup.exe`** | ~158 MB | Installer | Fully self-contained. No internet required during installation. |
| **`zylos_extension_3.0.zip`** 🌐 | 562 KB | Extension | Browser extension for Chrome, Edge, Firefox, and Brave. |

---

## 🌟 What's New

### 🛠️ Core Features
- **Advanced Downloader:** Powered by `yt-dlp` (Stable, Nightly, Master builds).
- **Media Conversion:** Integrated `FFmpeg` for seamless format processing.
- **Cloudflare WARP:** Built-in secure network traffic for bypassing restrictions.
- **Modular Design:** Choose specific plugins during installation.
- **Auto Startup:** Configure Zylos to launch on system boot.

### 🌐 Browser Extension
- **Size:** 562 KB
- **Compatibility:** Chrome, Edge, Firefox, Brave
- **Function:** Detects playable media and adds "Download with Zylos" button.
- **Installation:** Extract ZIP → Open Browser Extensions → Enable Developer Mode → Load Unpacked.

---

## 💻 Installation Guide

1. **Desktop App:** Download your preferred `.exe` from the table above and run it.
   - *Recommendation:* Use `Zylos_Universal_Setup.exe` for maximum flexibility.
2. **Browser Extension:** Download the `.zip`, extract it, and load it as an unpacked extension in your browser's developer settings.
