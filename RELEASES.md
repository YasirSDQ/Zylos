## ✨ What's New in v3.0

### Major Features

- 🎨 **Redesigned UI**: Modern, intuitive interface with improved navigation
- ⚡ **Faster Downloads**: Optimized yt-dlp integration for up to 30% faster downloads
- 🛠️ **Built-in Tools**: Integrated media converter, audio extractor, and metadata editor
- 🌐 **Browser Extension**: One-click video capture from any webpage
- 📱 **Responsive Design**: Better support for various screen sizes
- 🔔 **Smart Notifications**: Real-time download status updates
- 📊 **Download Queue Management**: Prioritize and organize your downloads
- 🎵 **Audio Extraction**: Extract audio directly during download
- 📝 **Subtitle Support**: Auto-download and embed subtitles
- 🔒 **Enhanced Security**: Improved validation and safety checks

### Improvements

- Reduced memory usage by 25%
- Faster startup time
- Better error handling and recovery
- Improved format detection
- Enhanced playlist support
- Smoother progress tracking

### Bug Fixes

- Fixed issue with certain YouTube video formats
- Resolved crash when downloading large playlists
- Fixed subtitle synchronization issues
- Corrected metadata extraction for some sites
- Fixed Windows Defender false positive (Universal Setup)

## 📋 System Requirements

### Minimum Requirements

- **OS**: Windows 10 (64-bit) or later
- **Processor**: Intel Core i3 or equivalent
- **RAM**: 4 GB
- **Disk Space**: 500 MB (plus space for downloaded content)
- **Internet**: Required for online setup and downloads

### Recommended Requirements

- **OS**: Windows 11 (64-bit)
- **Processor**: Intel Core i5 or better
- **RAM**: 8 GB or more
- **Disk Space**: 1 GB SSD
- **Internet**: High-speed connection for optimal download speeds

## 🔧 Installation Guide

### Quick Install (Recommended)

1. Download **Zylos_Universal_Setup.exe**
2. Run the installer
3. Follow the on-screen instructions
4. Launch Zylos from Start Menu or Desktop

### Alternative Installation Methods

#### Online Setup
Perfect for users with fast internet connections. The installer downloads only what you need.

#### Offline Setup
Ideal for installations without internet access or for deploying on multiple machines.

## 🏗️ Technology Stack

Zylos v3.0 is built with:

- **Framework**: [Flutter](https://flutter.dev/) - Cross-platform UI
- **Engine**: [yt-dlp](https://github.com/yt-dlp/yt-dlp) - Video downloading powerhouse
- **Media Processing**: [FFmpeg](https://github.com/yt-dlp/FFmpeg-Builds) - Audio/video conversion
- **Language**: Dart

## 🐛 Known Issues

- Some antivirus software may flag the installer (false positive). Add an exception if needed.
- Very old websites may not be supported by yt-dlp engine.
- 4K downloads require stable high-speed internet connection.
